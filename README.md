# Retail-IQ
An end-to-end Power BI dashboard analyzing sales, inventory, customer returns, shipping performance, and marketing spend for a multi region retail chain. Built a galaxy schema across 7 fact tables, cleaned a genuinely messy raw export, and wrote DAX measures covering revenue, inventory health, fulfillment, and marketing efficiency.
